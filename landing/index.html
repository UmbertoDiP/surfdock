Architettura

Un solo demone Electron, zero servizi separati: backend nel main process, UI React leggera, health endpoint per il watchdog.

[BOOT] avvia Docker Desktop se spento -> attende ready (max 120s)
[GATE] Iron Gate: 6 test zero-trust (killswitch, egress IP Mullvad, routing tun0, binding qBit, DNS, UDP tracker)
[ARMED] stato OK -> auto-resume torrent + telemetria 8s + poller Gate 60s
[HEALTH] http://localhost:5192/health per watchdog esterno e monitoraggio
[AUTOSTART] Login Item nativo (Windows/macOS), .desktop su Linux

Domande frequenti

Serve un abbonamento VPN?

No: SurfDock si integra con il tuo stack esistente (gluetun/Mullvad o qualunque container VPN del tuo server).

Cosa succede se cade la VPN?

I torrent vengono sospesi immediatamente e ripresi in automatico al ripristino del tunnel. Jellyfin resta raggiungibile in LAN.

Funziona senza finestra aperta?

Si: l'app vive nel tray e un watchdog la riavvia automaticamente se il health endpoint non risponde.
